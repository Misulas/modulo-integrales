# modulo-integrales

Microservicio `integrals`: calcula integrales a partir de texto LaTeX, por REST o desde el chat
con `/integralcalc <latex>`. Se integra con el chat base de la Unidad 3 (`users`, `channels`,
`messages`), que no forma parte de este repositorio y se levanta por separado.

- Uso, ejecución y pruebas: [`integrals/README.md`](integrals/README.md)
- Diseño, contratos y decisiones: [`integrals/docs/ARQUITECTURA.md`](integrals/docs/ARQUITECTURA.md)
